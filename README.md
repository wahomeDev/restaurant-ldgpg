# Savory Bites - Premium Restaurant Landing Page

An elegant landing page for a premium dining establishment featuring modern design and smooth animations.

## 🌐 Live Demo
[View Live Site](https://wahomedev.github.io/restaurant-landing-page/)

## 🛠️ Built With
- HTML5
- CSS3
- JavaScript

## 📋 Features
- Luxury gold and elegant color scheme
- Fully responsive design
- Menu showcase with pricing
- Reservation call-to-action
- Smooth scroll animations
- Feature highlights section
- Contact information footer

## 🎨 Design Highlights
- Sophisticated typography using Georgia and Playfair Display
- Gold accent color (#d4af37) for premium feel
- Hero section with overlay
- Card-based menu items
- Animated elements on scroll
